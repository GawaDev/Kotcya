# はじめに

Kotcyaは、画像の加工、画像情報の確認、C2PAコンテンツ認証情報の確認をブラウザで行うアプリです。

## 基本の流れ

1. プレビューへ画像をドロップするか、「画像を開く」を選びます。
2. 「加工」で見た目と大きさを調整します。
3. プレビューと「画像情報」で結果を確認します。
4. 形式を選び、「名前を付けて保存」を選びます。

PNG、JPEG、WebP、SVGを開けます。1ファイルの上限は30MBです。保存形式はPNG、JPG、WebPです。

## 画像の扱い

画像の読み込み、加工、解析、保存用データの作成はブラウザ内で行います。開いた画像自体をKotcyaのサーバーへ送信しません。

人物の切り抜きでは、MediaPipeの実行コードとモデル、WASMを外部サイトから取得します。詳しくは[セキュリティとプライバシー](../spec/security-privacy.md)を参照してください。

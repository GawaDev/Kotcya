# 画面と画像を開く

## 画面

デスクトップでは、左に加工、中央にプレビュー、右に画像情報があります。境界をドラッグすると幅を変えられます。

プレビュー上部の「別ウィンドウで表示」を選ぶと、プレビューを別ウィンドウへ移せます。元の画面から閉じることもできます。ブラウザがポップアップを止めた場合は、サイトのポップアップを許可してから再度選んでください。

幅768px以下では「ツール」「プレビュー」「情報」を切り替えて使います。各画面は縦にスクロールでき、操作ボタンはタッチしやすい大きさになります。

## アプリとして追加する

対応ブラウザでは、ブラウザのメニューから「アプリをインストール」または「ホーム画面に追加」を選べます。一度オンラインで開いた後は、通信できないときもワークスペースを起動できます。人物の切り抜きに必要なデータをまだ取得していない場合と、生成情報の初回確認では通信が必要です。

## 画像を開く

プレビューへファイルをドロップするか、「画像を開く」を選びます。画像を開いた後は「画像を変更」で別の画像を選べます。

対応形式は次のとおりです。

- PNG
- JPEG（JPG）
- WebP
- SVG

1ファイルは30MB以下です。一度に開ける画像は1枚です。SVGは表示時にブラウザで読み込み、保存時にはPNG、JPG、WebPの画素画像へ変換します。

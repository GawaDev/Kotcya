# 画像を加工する

画像を開き、左の「加工」で調整します。変更はプレビューへ反映されます。「元の画像」を押している間は加工前を確認できます。

## 人物と背景

- 「人物を切り抜く」は人物を検出し、背景を透明にします。
- 背景色、縁の色と太さを設定できます。
- 透明部分を基準に切り抜けます。

人物の切り抜きは初回にMediaPipeのモデルとWASMを外部から取得するため、通信環境によって時間がかかります。

## 色と質感

露出、ハイライト、シャドウ、ブラックポイント、HDR効果、明るさ、コントラスト、彩度、自然な彩度、暖かみ、色合いを調整できます。フィルタ、シャープネス、ぼかし、周辺光量も使用できます。

## 構図と出力寸法

回転、左右・上下反転、切り抜き比率、余白、ドロップシャドウを設定できます。

「画像の幅」は16〜8192pxです。空欄では元の幅を使います。縦横比は保たれ、縁、余白、影を加えた最終画像の寸法は指定幅より大きくなることがあります。

# 画像を保存する

1. 「加工」の下部でPNG、JPG、WebPのいずれかを選びます。
2. 「名前を付けて保存」を選びます。
3. 保存先とファイル名を決めます。

保存先を選ぶ機能にブラウザが対応していない場合は、ブラウザのダウンロード先へ保存されます。

## 形式の違い

- **PNG**: 透明部分を保持できます。
- **JPG**: 透明部分は白になります。
- **WebP**: 透明部分を保持でき、画像によっては容量を小さくできます。

SVGを開いた場合も、この3形式のいずれかへ変換して保存します。

## メタデータ

保存画像は表示中の画素から新しく作られます。元画像のEXIF、GPS、XMP、IPTC、C2PAなどのメタデータは引き継ぎません。位置情報を含む元画像を開いた場合でも、Kotcyaで保存した画像から元のGPS情報は削除されます。

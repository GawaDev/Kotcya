# 対応範囲

## ブラウザ

File API、Canvas、Object URL、Web Crypto APIを利用できる新しいブラウザを前提とします。保存先を選ぶ機能や別ウィンドウは、ブラウザの対応状況と設定により利用できない場合があります。

デスクトップでは3つのペインを同時表示し、境界を変更できます。モバイルでは加工、プレビュー、画像情報を切り替えます。

## C2PA

画像内のC2PAコンテンツ認証情報を読み取り、来歴、生成元の記録、署名、検証結果を表示します。C2PA情報がない画像や、対応外・破損した認証情報では制作元を確認できません。

この確認はC2PA認証情報に基づきます。画像内容を解析してAI生成の確率を求める一般的なAI画像判定ではありません。

## 制限

- 入力は1ファイル、30MB以下です。
- 入力形式はPNG、JPEG、WebP、SVGです。
- 保存形式はPNG、JPG、WebPです。
- 指定できる画像幅は16〜8192pxです。
- アニメーションは静止画として加工・保存します。

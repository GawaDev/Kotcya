# 画像処理仕様

画像処理はブラウザのCanvas上で行います。回転・反転、色調整、フィルタ、切り抜き、リサイズ、縁、余白、影を順に反映し、選択した形式で保存データを生成します。

プレビューは表示負荷を抑えるため最大寸法を制限して生成します。保存時は指定した出力幅を使って改めて生成するため、プレビューの画素数と保存画像の画素数は異なる場合があります。

人物の切り抜きにはMediaPipe Image Segmenterを使います。人物領域以外の透明度を0にし、人物領域を不透明にします。検出結果は画像の内容とモデルの特性により変わります。

JPEGでは透明部分を白で塗りつぶします。PNGとWebPでは透明部分を保持します。

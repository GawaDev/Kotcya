# 入出力仕様

## 入力

| 項目 | 対応範囲 |
| --- | --- |
| 形式 | PNG、JPEG、WebP、SVG |
| ファイル数 | 1回につき1ファイル |
| 容量 | 30MB以下 |

ブラウザが画像としてデコードできない内容は処理できません。アニメーション画像は情報を確認できますが、加工・保存結果は静止画です。

## 出力

| 形式 | 透明部分 |
| --- | --- |
| PNG | 保持 |
| JPG | 白で塗りつぶす |
| WebP | 保持 |

出力幅は16〜8192pxで指定できます。空欄では元画像の幅を使います。縁、余白、影は出力寸法へ加算されます。SVGは画素画像へ変換されます。

保存データはCanvasから新しく生成するため、元ファイルのメタデータは引き継ぎません。

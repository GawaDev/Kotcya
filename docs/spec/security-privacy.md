# セキュリティとプライバシー

## ブラウザ内で行う処理

画像の読み込み、プレビュー、加工、画像情報とメタデータの解析、ハッシュ計算、C2PA認証情報の確認、保存データの生成はブラウザ内で行います。開いた画像自体をKotcyaのサーバーへ送信しません。

## 人物の切り抜きで発生する通信

人物の切り抜きではMediaPipe Tasks Visionを使用します。初回利用時などキャッシュがない場合に、次の外部配信元から実行コード、WASM、人物切り抜きモデルを取得します。

- jsDelivr: MediaPipeのWASM
- Google Storage: Selfie Segmenterモデル

外部取得では通常のWeb通信としてIPアドレスなどの通信情報が配信元へ伝わりますが、Kotcyaの処理は画像ファイルをこれらの配信元へ送信しません。取得後はブラウザのキャッシュが使われる場合があります。

MediaPipeは診断情報や利用状況をGoogleへ送信します。初めて人物を切り抜くときに案内を表示し、利用者が「続ける」を選んだ場合だけMediaPipeを読み込みます。詳しくは[MediaPipe Tasksのプライバシー情報](https://developers.google.com/edge/mediapipe/solutions/tasks)を確認してください。

## 画像に含まれる情報

元画像のEXIFにGPS情報があれば画面へ表示します。画面を他人に見せる場合は位置情報に注意してください。

保存画像は画素から新しく生成し、EXIF、GPS、XMP、IPTC、C2PAなど元画像のメタデータを引き継ぎません。
